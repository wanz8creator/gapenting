## ✨ Fitur Utama

- 🎨 **Modern UI/UX:** Tampilan website eksekusi anti-zoom, responsif untuk Mobile/PC, dan tajam (High-DPI).
- 🤖 **Telegram Integration:** Kontrol penuh panel dari bot Telegram (termasuk fitur `/backup` otomatis file zip).
- 📱 **Baileys Library:** Koneksi WhatsApp super ringan dengan metode Multi-Device.
- ⚡ **Auto Join Channel:** Bot dapat bergabung ke channel WhatsApp (Newsletter) secara otomatis dengan sistem anti-spam.
- 🔒 **Secure Sessions:** Penyimpanan sesi login yang aman dan tidak memberatkan server.
